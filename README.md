## 能做什么

### 🔍 模式一：持仓诊断

```
你说："512480 和 513650 怎么样"
它拉取：夏普比率、最大回撤、溢价率、资金流向、宏观背景
它输出：一份结构化对比报告 + 风险提醒
```

**诊断维度：**
- 📈 收益表现（近1月/3月/1年回报）
- ⚖️ 风险调整（夏普比率、年化波动率、最大回撤）
- ⚠️ 折溢价风险（市价 vs 净值偏离，自动标注异常）
- 💰 资金流向（主力净流入/流出方向）
- 🏆 同赛道排名（同类 ETF 横向对比）
- 🌍 宏观背景（中美通胀、利率、地缘风险）

### 🚀 模式二：机会扫描

```
你说："今天有什么 ETF 机会"
它扫描：全市场折价/资金异动/动量/超跌/放量
它输出：按综合得分排名的机会列表
```

**扫描维度：**
- 🟢 折价机会（市价 < 净值）
- 💰 资金涌入（主力大幅流入）
- 🚀 动量延续（近1月涨幅最强）
- 📉 超跌反弹（短期急跌，可能反弹）
- ⚠️ 溢价风险（远离这些）

## 快速开始

### 安装

```bash
# 克隆到 ZCode skills 目录
git clone https://github.com/<your-username>/etf-diagnosis-skill.git ~/.agents/skills/etf-diagnosis
```

### 使用

在 ZCode 对话中直接说：

```
"帮我看看我的ETF持仓 512480 513650"
"今天有什么值得关注的ETF"
"ETF调仓建议"
"扫一下市场异动"
```

或命令行调用：

```bash
# 诊断模式
python3 scripts/diagnose.py 512480 513650

# 扫描模式
python3 scripts/scan.py
```

## 为什么做这个

中国有几千万 ETF/LOF 持有者，券商 App 只给行情，不给诊断。普通投资者面对一堆指标（夏普、溢价率、最大回撤）不知道怎么解读。

这个技能把我在量化分析中实际使用的流程自动化了——原来花 2 小时手动查的东西，现在一句话出报告。
